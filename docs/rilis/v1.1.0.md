## Pemindai LJK v1.1.0

**Unduh:** `OMRChecker-Setup-1.1.0.exe` di bawah, lalu jalankan untuk memasang. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Baru
- **Ingat folder ini untuk ujian berikutnya:** centang baru di Langkah 3 (folder scan) dan Langkah 4 (folder hasil). Bawaannya tidak dicentang: setelah rekap diekspor atau saat *Ujian baru*, kolom folder dikosongkan, jadi scan ujian berikutnya tidak tercampur dengan LJK lama. File di folder tidak dihapus. Centang bila ingin selalu memakai folder yang sama.

### Catatan
- Ujian yang belum diekspor (misalnya proses berhenti di tengah) tetap dibuka lagi dengan foldernya, supaya bisa dilanjutkan.
- Ujian yang sudah selesai tetap bisa dibuka lagi lewat *Buka ujian lama...*.
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
