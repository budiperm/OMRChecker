## Pemindai LJK v1.9.0

**Unduh:** `OMRChecker-Setup-1.9.0.exe` di bawah, lalu jalankan untuk memasang. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Pembaruan Tampilan
- **Antarmuka lebih bersih, ringkas, dan elegan.** Palet warna modern dengan kartu putih berbingkai halus di seluruh langkah Wizard (1–6), dialog koreksi, dan dialog scan scanner.
- **Tampilan ringkas (Dashboard) lebih lega.** Empat pengaturan utama kini tersusun dalam grid kartu 2×2 bernomor dengan label status berwarna (`✓ Siap` / `Belum diisi`), panel kesiapan proses yang jelas, serta tombol pindah mode (**Tampilan ringkas** ↔ **Mode langkah**) langsung 1 klik.
- **Kartu ringkasan statistik (KPI).** Jumlah LJK, perlu dicek, rata-rata, nilai tertinggi, terendah, dan kelulusan kini tampil sebagai kartu ringkas yang mudah dipindai pada layar *Proses & periksa* serta *Rekap & ekspor*.
- **Sidebar langkah lebih interaktif.** Efek hover saat kursor diarahkan, sorotan kapsul membulat pada langkah aktif, dan penanda hijau untuk langkah yang sudah selesai.

### Catatan
- Seluruh alur kerja, format template `.ljk`, kunci `.kunci`, dan file hasil ujian tetap kompatibel penuh dengan versi sebelumnya.
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
