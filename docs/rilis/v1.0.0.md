## Pemindai LJK v1.0.0

Rilis stabil pertama. Pemindai LJK sekarang perangkat lunak bebas dan sumber terbuka (GNU AGPL-3.0) dan bisa dipakai untuk ujian sekolah, seleksi, maupun tes perusahaan.

**Unduh:** `OMRChecker-Setup-1.0.0.exe` di bawah, lalu jalankan untuk memasang. Semua komponen sudah ada di dalam installer, termasuk driver TWAIN 64-bit, jadi tidak perlu internet. Yang perlu dipasang sendiri hanya driver scanner dari produsennya. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Baru
- **Installer resmi** dengan lisensi, pintasan Start Menu dan desktop, serta uninstaller.
- **Istilah netral:** peserta, No. Peserta, Kelompok, Nilai batas lulus, Lulus/Tidak lulus. Daftar peserta dengan kolom NIP, NIK, atau Divisi langsung dikenali.
- **Buka ujian lama:** kunci, koreksi, dan daftar peserta setiap ujian tersimpan di folder hasilnya. Tombol *Buka ujian lama...* membukanya lagi, misalnya untuk ekspor ulang atau koreksi susulan.
- **Laporan per peserta (PDF):** satu halaman untuk setiap peserta, berisi identitas, nilai, peringkat, dan jawaban dibandingkan dengan kunci.
- **Peringkat** di rekap Excel, dan pilihan urutan rekap: nilai tertinggi, kelompok lalu nama, atau nama file.
- **Lanjutkan pemeriksaan:** setelah *Stop*, atau setelah scan baru ditambahkan ke folder, *Proses LJK* hanya memeriksa LJK yang belum diperiksa.
- **Ekspor/impor template** sebagai satu file `.ljk` untuk dipakai di komputer lain.
- **Tombol Bantuan:** panduan, folder data & log, tautan cek versi terbaru, dan Tentang (versi dan lisensi).

### Perbaikan
- Daftar peserta berformat `.xls` (Excel 97-2003) kini terbaca.
- Bilah kemajuan memakai sinyal langsung dari pemroses, dan PDF berhalaman banyak dihitung per halaman.
- Kolom daftar peserta tidak lagi terpotong di layar kecil.

### Perubahan
- Tombol *Mode lanjutan* dihapus dari layar utama. Mode ini masih tersedia lewat `OMRChecker.exe --lanjutan`.

### Catatan
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
- Ujian yang diperiksa dengan versi sebelum 1.0.0 belum punya file `ujian.json`, jadi tidak bisa dibuka lewat *Buka ujian lama...*.
