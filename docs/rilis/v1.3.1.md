## Pemindai LJK v1.3.1

**Unduh:** `OMRChecker-Setup-1.3.1.exe` di bawah, lalu jalankan untuk memasang. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Perbaikan
- **Koreksi nyasar ke LJK lain di subfolder:** bila folder scan berisi subfolder dengan nama file yang sama (misalnya `7A\scan_0001.jpg` dan `7B\scan_0001.jpg`, karena scanner mengulang nomor di tiap folder), koreksi pada satu LJK ikut mengubah LJK lain yang bernama sama. Sekarang tiap LJK dikenali dengan nama subfoldernya (`7A/scan_0001.jpg`), jadi koreksi hanya berlaku untuk LJK itu. Koreksi lama yang tersimpan ikut dipindahkan bila tidak ada nama kembar.
- **Koreksi hilang setelah melihat template lain:** memilih template lain di langkah 1 lalu kembali ke template semula menghapus semua koreksi manual. Sekarang koreksi disimpan per template seperti kunci jawaban dan muncul lagi saat template semula dipilih.
- **Ujian berikutnya dianggap sudah pernah diekspor:** setelah rekap diekspor dan aplikasi dibuka lagi untuk ujian baru, langkah 6 menulis "Ada perubahan sejak ekspor terakhir" dan jendela simpan Excel menawarkan file rekap ujian sebelumnya, sehingga rekap lama bisa tertimpa. Sekarang ujian baru berstatus "Belum diekspor" dan jendela simpan dibuka di folder hasil ujian baru.
- **"Ada perubahan sejak ekspor terakhir" padahal tidak ada perubahan:** muncul hanya karena sempat memilih template lain di langkah 1 lalu kembali. Sekarang tidak lagi.

### Catatan
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
