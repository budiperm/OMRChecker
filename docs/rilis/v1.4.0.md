## Pemindai LJK v1.4.0

**Unduh:** `OMRChecker-Setup-1.4.0.exe` di bawah, lalu jalankan untuk memasang. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Baru
- **Simpan & buka file kunci jawaban (langkah 2):** tombol **Simpan kunci...** menyimpan kunci jawaban ke file `.kunci`, termasuk kunci tiap kode naskah, kolom kode naskah, bobot, pilihan "Harus diisi berurutan", dan aturan penilaian. Tombol **Buka kunci...** memakainya lagi. Berguna bila LJK tetap tetapi soal berubah: pilih template di langkah 1, lalu buka file kunci yang cocok. Bila isi file tidak cocok dengan template (bagian tidak ada, kunci lebih panjang dari jumlah soal, kolom kode tidak ada), aplikasi memberi tahu apa yang perlu dicek.

### Perbaikan
- **Kunci tidak hilang saat ganti pilihan:** pindah antara "Satu kunci untuk semua LJK" dan "Kunci berbeda per kode naskah" tidak lagi menghapus kunci yang sudah diketik. Kunci tiap pilihan disimpan; yang dinilai adalah pilihan yang aktif.
- **"Harus diisi berurutan" per kode naskah:** dengan kunci per kode naskah, centang ini sekarang diatur sendiri untuk tiap kode dan dipakai saat menilai LJK kode itu. Pengaturan dari versi sebelumnya tetap berlaku untuk semua kode sampai diubah.

### Catatan
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
