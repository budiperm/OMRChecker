## Pemindai LJK v1.3.0

**Unduh:** `OMRChecker-Setup-1.3.0.exe` di bawah, lalu jalankan untuk memasang. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Baru
- **Harus diisi berurutan (langkah 2):** centang per bagian soal. Begitu ada soal kosong, jawaban sesudahnya di bagian itu tidak dihitung (dinilai seperti kosong). Contoh: 20 soal, soal 9 kosong, maka jawaban soal 10–20 tidak dihitung. Defaultnya mati. LJK yang terkena ditandai di catatan ("Soal 9 kosong: 11 jawaban sesudahnya tidak dihitung") supaya bisa dicek bila soal itu sebenarnya diisi tapi tipis. Rekap Excel dan CSV mendapat kolom **Tidak dihitung**, sheet Jawaban menandai jawaban itu dengan warna kuning, dan laporan PDF mencoretnya.
- **Kunci jawaban menempel di template:** kunci, bobot, kode naskah, dan pilihan berurutan disimpan per template. Ganti template di langkah 1 tidak lagi membawa kunci template lain; kembali ke template semula, kuncinya muncul lagi.
- **Ekspor CSV (langkah 6):** tombol **Ekspor CSV...** menyimpan rekap nilai plus jawaban tiap soal dalam satu tabel CSV (UTF-8, dipisah koma) untuk diimpor ke program lain.

### Catatan
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
