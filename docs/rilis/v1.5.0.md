## Pemindai LJK v1.5.0

**Unduh:** `OMRChecker-Setup-1.5.0.exe` di bawah, lalu jalankan untuk memasang. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Baru
- **Ekspor lanjutan (langkah 6):** tombol **Ekspor lanjutan...** membuka jendela untuk memilih sendiri kolom yang diekspor (kolom rekap, nilai per bagian, jawaban tiap soal), mengatur urutannya, dan mengganti judul kolom, misalnya "No. Peserta" menjadi "NIS". Hasilnya satu tabel Excel atau CSV dengan judul di baris pertama, cocok untuk format rapor atau sistem lain. Pengaturan bisa disimpan sebagai format dengan nama, dan pengaturan terakhir otomatis muncul lagi. Tombol ekspor Excel dan CSV yang biasa tidak berubah.

### Perubahan kecil
- Di langkah 6, tombol **Buka folder hasil** dan **Ujian baru** pindah ke baris kedua, dan status ekspor ada di bawahnya, supaya semua tombol muat di layar kecil.

### Catatan
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
