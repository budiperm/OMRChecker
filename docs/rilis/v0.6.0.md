## Pemindai LJK v0.6.0

**Unduh:** `OMRChecker-windows.zip` di bawah, ekstrak, lalu jalankan `OMRChecker.exe` (Windows 10/11 64-bit, tidak perlu memasang Python). Panduan bergambar ada di `PANDUAN.pdf` di dalam zip.

### Baru
- **Scan langsung dari scanner** di Langkah 3 (TWAIN dan WIA): semua lembar di ADF di-scan sekaligus ke folder LJK, 200/300 dpi, abu-abu/berwarna, A4 atau F4. Sudah dicoba dengan Epson DS-410.
- **Tampilan baru** bergaya Windows 11: daftar langkah di sisi kiri, font Segoe UI, tombol utama berwarna.
- **Ikon aplikasi baru** di exe, taskbar, dan jendela.
- **Panduan PDF** langkah demi langkah (`PANDUAN.pdf`).
- **Tombol Selesai yang lebih berguna:** bila rekap belum diekspor (atau berubah sejak ekspor terakhir), program menawarkan ekspor ke Excel sebelum ditutup. Bila sudah, muncul layar "Pemeriksaan selesai" (buka rekap, buka folder hasil, ujian baru).
- Status ekspor di Langkah 6 (belum / sudah / ada perubahan).

### Perubahan
- Langkah 5 "Proses & periksa" tidak lagi berjalan sendiri saat dibuka: klik **Proses LJK** untuk mulai.

### Perbaikan
- Lembar kosong (mis. halaman belakang scan dua sisi) tidak lagi menggagalkan seluruh proses; hanya lembar itu yang ditandai "LJK tidak terbaca".

### Catatan
- Scanner harus sudah dipasang drivernya dari situs produsen. Cek scanner yang terdeteksi: `OMRChecker-debug.exe --cek-scanner` dari Command Prompt.
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan: klik **More info** lalu **Run anyway**.
