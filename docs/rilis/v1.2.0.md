## Pemindai LJK v1.2.0

**Unduh:** `OMRChecker-Setup-1.2.0.exe` di bawah, lalu jalankan untuk memasang. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Baru
- **Arsipkan scan lama:** tombol baru di Langkah 3. Sebelum scan ulang, file scan lama dipindah ke subfolder `_arsip\[tanggal jam]` di folder scan (tidak dihapus, tidak ikut diproses lagi), jadi LJK tidak terhitung dua kali. Koreksi manual lama dibuang dan Langkah 4 otomatis memilih *Hapus hasil lama lalu proses ulang*.
- **Jumlah LJK sebelum diproses:** Langkah 5 langsung menampilkan berapa LJK yang akan diproses di samping bilah kemajuan, sebelum tombol *Proses LJK* ditekan.

### Catatan
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
