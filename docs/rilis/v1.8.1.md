## Pemindai LJK v1.8.1

**Unduh:** `OMRChecker-Setup-1.8.1.exe` di bawah, lalu jalankan untuk memasang. Versi portabel tanpa instalasi: `OMRChecker-windows.zip`. Syarat: Windows 10/11 64-bit.

### Perbaikan
- **Scan PDF gagal di v1.8.0.** Memproses LJK berformat PDF (dan ekspor PDF per peserta) berhenti dengan pesan *No such file or directory ... pymupdf\layout ... .yaml*. Penyebabnya komponen pembaca PDF versi baru yang ikut terpasang saat program dibangun. Sekarang PDF terbaca lagi seperti biasa, dan setiap rilis diuji dulu membaca PDF sebelum diterbitkan.

### Catatan
- Saat pertama dibuka, Windows SmartScreen mungkin memberi peringatan karena program belum bertanda tangan digital. Klik **More info** lalu **Run anyway**.
